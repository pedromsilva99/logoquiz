# Imagens dos logos

Cada logo tem duas versões, com o mesmo nome de ficheiro (`image_key`):

- `hidden/<image_key>.<ext>` — versão incompleta, mostrada antes de acertar
- `full/<image_key>.<ext>` — versão completa, mostrada depois de acertar

Extensões aceites: `.svg`, `.png`, `.webp`, `.jpg`, `.jpeg`.
Enquanto não existir ficheiro, o backend serve um placeholder.
